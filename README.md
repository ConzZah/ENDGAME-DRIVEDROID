# ENDGAME-DRIVEDROID

for all that don't want to search for a usb drive when installing endgame, i made a drivedroid image.

## REQUIREMENTS
- any android device rooted with magisk
- the files in this repository
- a controller to usb cable
- a bit of patience

## GUIDE
- download ENDGAME+DRIVEDROID.zip and extract it
- go into magisk > modules and install DriveDroid-fix-Magisk.zip, then reboot
- install drivedroid-free-0.10.50.apk
- open drivedroid, mount Endgame-Drivedroid.img as read-only
- connect your rooted android device with your xbox via usb
- choose the (virtual) memory-unit

## NOTES
if you get a black screen, wait for some time and then hit the eject button.
this will soft reboot your console.
then, choose the (virtual) memory unit again and it should work.
